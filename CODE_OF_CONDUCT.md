# Code of Conduct

We want this project to be welcoming and productive for everyone.

## Expected behavior
- Be respectful and assume good intent
- Give and accept constructive feedback gracefully
- Focus on what is best for the project and its users

## Unacceptable behavior
- Harassment, discrimination, insults or personal attacks
- Publishing others' private information
- Trolling, or sustained disruption of discussions

## Enforcement
Maintainers may edit or remove comments, issues and contributions that violate this code, and may restrict participation. To report a problem, contact the maintainers through a private GitHub message or the contact listed on the maintainer's profile.

This policy applies in all project spaces, including issues, pull requests and discussions.
