# Security Policy

## Supported versions
Only the latest release on `main` receives security fixes.

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include steps to reproduce and the affected version.

You can expect an acknowledgement within a few days. Fixes are released as soon as they are ready and credited to the reporter unless you prefer otherwise.

## Scope notes
Plugins run with full access to the page, so only install plugins you trust. Nexus reads and writes only the files you explicitly open or save through the browser's file dialogs.
